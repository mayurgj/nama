# NAMA

Nuvio local-scraper providers for multi-audio Indian-dub anime and movies (Hindi, Tamil, Telugu, Malayalam, Bengali, English, Japanese) in 1080p and 720p.

## Install

In Nuvio, go to Settings → Plugins (Local Scrapers) → add repository:

```
https://raw.githubusercontent.com/mayurgj/nama/main/manifest.json
```

## Providers

| Provider | Site | Types | Audio |
|---|---|---|---|
| AnimeSalt | animesalt.cx | movie, tv | HI • TA • TE • EN • JA |
| WatchAnimeWorld | watchanimeworld.one | movie, tv | HI • TA • TE • ML • BN • EN • JA |
| MultiMovies | multimovies.wtf (rotating mirror) | movie, tv | HI • TA • TE • EN • JA |

Building, testing, sorting and how the providers work: see [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).
